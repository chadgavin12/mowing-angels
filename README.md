# Mowing Angels

A responsive website + installable Progressive Web App (PWA) prototype for a free lawn-care volunteer program.

## Included
- Home/mission page
- Request Free Lawn Care form
- Volunteer signup
- Sponsor page
- Admin dashboard prototype
- Mobile-responsive UI
- Installable PWA manifest/service worker
- Browser-local prototype storage

## Run
Open `index.html` in a browser. For PWA installation/service-worker behavior, serve the folder from a local HTTPS/HTTP server (for example VS Code Live Server).
